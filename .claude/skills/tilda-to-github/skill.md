# Skill: Перенос сайта с Tilda на GitHub Pages

## 🎯 Когда использовать этот скилл:
- Сайт на Tilda заблокирован из-за неоплаты
- Нужно перенести контент с Tilda на бесплатный хостинг
- Клиент хочет сэкономить на хостинге Tilda (~3000-5000₽/год)
- Есть сохранённые файлы с Tilda (HTML + папка _files)

## 📋 ПОШАГОВЫЙ ПЛАН

### ЭТАП 1: Анализ сохранённых файлов Tilda

1. Проверить структуру папки проекта:
   - Должен быть HTML-файл (например, `Тильда.html`)
   - Должна быть папка с ресурсами (например, `Тильда_files/`)
   - Могут быть дополнительные страницы в отдельных папках

2. Проанализировать HTML-файл:
   ```bash
   head -100 "Тильда.html"
Извлечь ключевую информацию:
Название школы/бренда
Заголовки всех секций
Описания услуг/курсов
Контактные данные
Цены (если есть)
Отзывы клиентов
ЭТАП 2: Создание структуры нового сайта
Создать файлы:
project-folder/
├── index.html          # Главная страница
├── styles.css          # Стили
├── script.js           # Интерактивность
└── assets/
    └── images/         # Изображения (скопировать из Tilda_files)
ЭТАП 3: Создание HTML-структуры
Стандартная структура для сайта онлайн-школы:

ЭТАП 4: Создание CSS-стилей
Использовать CSS-переменные для цветовой схемы:

  --color-primary: #2563eb;      /* Основной цвет */

ЭТАП 6: Подготовка к деплою на GitHub
Создать файл CNAME с доменом:
ваш-домен.ru
Создать .gitignore:
.DS_Store
node_modules/
*.log
ЭТАП 7: Деплой на GitHub Pages
Команды для терминала:
cd ~/путь/к/проекту
git init
git add .
git commit -m "Initial commit: перенос сайта с Tilda"
git remote add origin git@github.com:username/username.github.io.git
git branch -M main
git push -u origin main --force
ЭТАП 8: Настройка GitHub Pages
Открыть Settings → Pages в репозитории
Source: main branch, / (root)
Custom domain: ваш-домен.ru
Включить "Enforce HTTPS"
Сохранить
ЭТАП 9: Настройка DNS в регистраторе домена
Для Reg.ru (или другого регистратора):
A-записи (4 штуки):
@ → 185.199.108.153
@ → 185.199.109.153
@ → 185.199.110.153
@ → 185.199.111.153
CNAME-запись:
www → username.github.io
ЭТАП 10: Проверка
Подождать 30-60 минут (обновление DNS)
Проверить на https://dnschecker.org
Открыть сайт по домену
Проверить HTTPS (зелёный замочек)
⚠️ ВАЖНЫЕ НЮАНСЫ
Изображения: Скопировать из папки Tilda_files в assets/images
Шрифты: Если используются кастомные шрифты Tilda — заменить на Google Fonts
Формы: Tilda-формы не будут работать — заменить на внешние сервисы (Formspree, Google Forms) или убрать
Анимации Tilda: Воссоздать через CSS/JS
SEO: Добавить meta-теги (title, description, Open Graph)

🔧 ТИПИЧНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
Проблема: Сайт не открывается после настройки DNS
Решение: Подождать 1-24 часа, проверить DNS на dnschecker.org
Проблема: HTTPS не работает
Решение: Включить "Enforce HTTPS" в настройках GitHub Pages, подождать 30 минут
Проблема: Изображения не загружаются
Решение: Проверить пути в HTML (должны быть относительными: assets/images/photo.jpg)
Проблема: Шрифты отображаются неправильно
Решение: Подключить Google Fonts в <head> HTML
