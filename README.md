# Lola Parle - Online French School

Многостраничный веб-сайт онлайн-школы французского языка на основе GitHub Pages.

## 📋 Структура проекта

```
github-pages/
├── index.html              # Главная страница
├── contacts.html           # Контакты и форма обратной связи
├── pricing.html            # Прайс-лист и пакеты обучения
├── reviews.html            # Отзывы студентов
├── privacy.html            # Политика конфиденциальности
├── 404.html                # Страница ошибки 404
├── css/
│   ├── style.css           # Основные стили
│   ├── responsive.css      # Адаптивный дизайн (mobile-first)
│   └── animations.css      # Анимации и переходы
├── js/
│   └── main.js             # Основной JavaScript
└── assets/
    ├── images/             # Изображения
    ├── fonts/              # Пользовательские шрифты
    └── icons/              # SVG иконки
```

## 🎨 Особенности

- **Mobile-first дизайн** — адаптация для всех устройств (320px - 1200px+)
- **Быстрая загрузка** — оптимизированные CSS и JS
- **Переиспользуемые компоненты** — карточки, кнопки, формы
- **Анимации** — плавные переходы и эффекты (fade-in, slide, scale)
- **Интерактивность** — мобильное меню, smooth scroll, валидация форм
- **Доступность** — ARIA labels, семантический HTML
- **SEO оптимизация** — meta tags, структурированные данные

## 🚀 Деплой на GitHub Pages

### Способ 1: Использование ветки `gh-pages`

```bash
# Перейдите в корень репозитория
cd ../

# Создайте ветку gh-pages (если её нет)
git checkout --orphan gh-pages

# Очистите содержимое
git rm -rf .

# Скопируйте файлы из github-pages/
cp -r github-pages/* .
cp github-pages/.gitignore . 2>/dev/null || true

# Добавьте и отправьте
git add .
git commit -m "Deploy Lola Parle site to GitHub Pages"
git push -u origin gh-pages
```

### Способ 2: Использование главной ветки

Если вы хотите использовать главную ветку:

1. Скопируйте содержимое `github-pages/` в корень репозитория
2. В GitHub Settings → Pages выберите `main` как источник
3. Сайт будет доступен по адресу: `https://username.github.io/repo-name`

### Настройка формы обратной связи

В `js/main.js` найдите функцию `submitForm()` и:

**Вариант 1: Formspree (бесплатно)**
```javascript
fetch('https://formspree.io/f/YOUR_FORM_ID', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data)
})
```

**Вариант 2: Netlify Forms**
Добавьте атрибут `netlify` в тег `<form>`:
```html
<form id="contactForm" class="form" netlify>
```

**Вариант 3: Собственный backend**
Измените endpoint в `submitForm()` на ваш API.

## 📦 Производительность

### Размер файлов
- **HTML**: ~15-20 KB на странице
- **CSS**: ~50 KB (все 3 файла вместе)
- **JS**: ~15 KB
- **Total**: ~80-100 KB перед сжатием gzip

### Оптимизация
1. CSS разделен на модули (style, responsive, animations)
2. JS использует vanilla JS без зависимостей
3. Изображения должны быть оптимизированы до добавления
4. GitHub Pages автоматически включает gzip сжатие
